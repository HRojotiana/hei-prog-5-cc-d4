# 🐍 HEI Snake Game - Java Console

## Référence binôme
- STD22095 

Un mini-jeu Snake en Java fonctionnant dans la console, conçu pour appliquer les principes de **Clean Code** :

- **DRY** (Don't Repeat Yourself)
- **KISS** (Keep It Simple, Stupid)
- **YAGNI** (You Aren’t Gonna Need It)
- **Naming** (Nommage clair)
- **Factory Pattern**
- **Builder Pattern**
- **State Pattern**
- **Strategy Pattern**

---

## 🎮 Fonctionnement

- Une grille 10x10
- Le serpent se déplace automatiquement
- De la nourriture apparaît aléatoirement
- Le joueur entre `W`, `A`, `S`, `D` pour diriger le serpent
- Le jeu se termine si le serpent percute un mur ou lui-même

---
